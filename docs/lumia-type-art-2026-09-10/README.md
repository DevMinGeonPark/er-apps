PNG 저장·기기 공유·PDF 인쇄는 `LumiaTypeExport.render()`의 1080×1512 카드를 함께 사용합니다. PDF는 카드 이미지를 준비한 뒤 A4 한 페이지로 인쇄하며 PNG와 같은 그림·문구·비율을 담습니다. 기기의 공유 메뉴가 지원되면 사용자가 카카오톡을 선택할 수 있고, 미지원 환경에서는 PNG 저장과 링크 복사를 제공합니다. 검증에서는 공유 메뉴와 인쇄 창을 대체하여 실제 전송 없이 동작을 확인합니다.
